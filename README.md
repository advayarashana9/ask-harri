# Ask Harri

Ask Harri is an AI-powered multilingual mental health resource navigator designed to help Harris County residents more easily find and understand local mental health services.

It acts as a conversational digital front door to care, allowing users to ask questions through text or voice and receive guidance toward relevant resources.

## Features


- Real-time AI voice conversations
- Multilingual mental health resource navigation
- Gemini Live integration
- Retrieval-Augmented Generation (RAG)
- Harris County resource guidance
- Safety guardrails for sensitive conversations
- Simple and accessible user interface
- Personalized care summaries

## Tech Stack

- React
- TypeScript
- Gemini API
- Gemini Live
- Retrieval-Augmented Generation (RAG)
- Google AI Studio
- Vite

## How It Works

1. A user asks Ask Harri a question through text or voice.
2. Ask Harri interprets the user's needs and context.
3. The system retrieves relevant mental health resource information.
4. Gemini generates a conversational response explaining available options.
5. The user can continue the conversation or receive a personalized summary.

## Example Questions

- "I live in Alief and need counseling."
- "How do I request help from an MCOT team?"
- "Are there affordable mental health clinics near me?"
- "Can you explain these resources in Spanish?"

## Impact

Ask Harri has been beta tested with 250+ Harris County residents, with development focused on improving accessibility for communities facing language and information barriers.

## Motivation

Ask Harri was created to explore how AI can make public services easier to navigate.

Community testing showed that even when resources exist, complicated interfaces and language barriers can prevent residents from finding the help they need.

The project follows a simple principle:

**Listen first. Build second.**

## Disclaimer

Ask Harri is a resource-navigation tool and is not a replacement for professional medical advice, diagnosis, emergency services, or treatment.

If you or someone else is in immediate danger, contact emergency services or an appropriate crisis service.
